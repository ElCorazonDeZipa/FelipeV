Pasos de configuración
1️⃣ Google Sheets: Crea el Sheets con corazonzipa@gmail.com → copia el ID del URL → pégalo arriba → Guardar
2️⃣ Apps Script: Ve a script.google.com → ejecuta inicializarSheets() → acepta permisos de Calendar y Tasks
3️⃣ Google Maps: console.cloud.google.com → habilita Maps JavaScript API → copia la key → pégala arriba
4️⃣ Google Tasks: Configurado automáticamente cuando aceptes permisos en el paso 2
5️⃣ Referidos del Formulario: En la pestaña Referidos → botón "📋 Sync Formulario". El Apps Script v6 tiene leerHojaExt.
🔧 Si dice "Conectando..." o "Sin conexión":
1. Abre script.google.com con corazonzipa@gmail.com
2. Desplegar → Administrar despliegues → ✏️ Editar
3. Ejecutar como: Yo (corazonzipa@gmail.com)
4. Quién puede acceder: Cualquier persona (sin Google)
5. Versión: Nueva versión → Guardar → Desplegar
6. Acepta los permisos si los pide
7. Regresa aquí → botón 🔌 Probar conexión
